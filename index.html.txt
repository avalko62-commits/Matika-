        <h2>1. POSTUPNOSTI</h2>
        
        <h3>A. Teória</h3>
        <p>Postupnosť je funkcia, ktorej definičným oborom je množina prirodzených čísel $\mathbb{N} = \{1, 2, 3, \dots\}$. [cite_start]Značí sa $\left(a_n\right)$ a každý prvok $a_n$ sa nazýva n-tý člen postupnosti. [cite: 2, 3]</p>
        
        <h4>Aritmetická postupnosť (AP)</h4>
        <ul>
            <li>Vznikne pripočítaním konštantného **rozdielu** $d$ k predchádzajúcemu členu: $a_{n+1} = a_n + d$.</li>
            [cite_start]<li>N-tý člen sa vypočíta vzorcom: $a_n = a_1 + (n-1)d$[cite: 3].</li>
            <li>Súčet prvých $n$ členov: $S_n = \frac{n}{2}(a_1 + a_n)$.</li>
        </ul>

        <h4>Geometrická postupnosť (GP)</h4>
        <ul>
            <li>Vznikne vynásobením predchádzajúceho člena konštantným **kvocientom** $q$: $a_{n+1} = a_n \cdot q$.</li>
            <li>N-tý člen sa vypočíta vzorcom: $a_n = a_1 \cdot q^{n-1}$.</li>
            <li>Súčet prvých $n$ členov: $S_n = a_1 \frac{q^n - 1}{q - 1}$, pre $q \neq 1$.</li>
        </ul>

        <h3>B. Príklady a precvičenie</h3>
        
        <div class="example">
            <h4>Príklad 1 (AP)</h4>
            <p>Nájdite 10. člen aritmetickej postupnosti, ak je dané $a_1=3, d=5$.</p>
            <button onclick="showSolution('sol1')">Ukáž riešenie</button>
            <p id="sol1" class="solution">
                $a_{10} = a_1 + (10-1)d = 3 + 9 \cdot 5 = 3 + 45 = \mathbf{48}$.
            </p>
        </div>
        
        <div class="example">
            <h4>Príklad 2 (GP)</h4>
            <p>Nájdite 5. člen geometrickej postupnosti, ak je dané $a_1=2, q=3$.</p>
            <button onclick="showSolution('sol2')">Ukáž riešenie</button>
            <p id="sol2" class="solution">
                $a_5 = a_1 \cdot q^{5-1} = 2 \cdot 3^4 = 2 \cdot 81 = \mathbf{162}$.
            </p>
        </div>

        <h2>2. STEREOMETRIA</h2>
        
        <h3>A. Teória</h3>
        <p>Stereometria je časť geometrie, ktorá sa zaoberá štúdiom telies v trojrozmernom priestore. [cite_start]Skúma telesá ako sú: kváder, kocka, hranol, ihlan, valec, kužeľ a guľa. [cite: 4]</p>

        <h4>Základné vzorce:</h4>
        <table style="width:100%; text-align:left; border-collapse:collapse;">
            <thead>
                <tr style="background-color:#eee;"><th>Teleso</th><th>Objem ($V$)</th><th>Povrch ($S$)</th></tr>
            </thead>
            <tbody>
                <tr><td>**Kocka (strana $a$)**</td><td>$V = a^3$</td><td>$S = 6a^2$</td></tr>
                <tr><td>**Kváder (strany $a, b, c$)**</td><td>$V = a \cdot b \cdot c$</td><td>$S = 2(ab+ac+bc)$</td></tr>
                <tr><td>**Valec (polomer $r$, výška $h$)**</td><td>$V = \pi r^2 h$</td><td>$S = 2\pi r(r+h)$</td></tr>
            </tbody>
        </table>

        <h3>B. Príklady a precvičenie</h3>
        
        <div class="example">
            <h4>Príklad 3 (Kváder)</h4>
            <p>Vypočítajte objem kvádra, ak $a=3 \text{ cm}, b=4 \text{ cm}, c=5 \text{ cm}$.</p>
            <button onclick="showSolution('sol3')">Ukáž riešenie</button>
            <p id="sol3" class="solution">
                $V = a \cdot b \cdot c = 3 \cdot 4 \cdot 5 = \mathbf{60 \text{ cm}^3}$.
            </p>
        </div>
        
        <div class="example">
            <h4>Príklad 4 (Kocka)</h4>
            <p>Aká je dĺžka hrany kocky, ktorej povrch je $24 \text{ cm}^2$?</p>
            <button onclick="showSolution('sol4')">Ukáž riešenie</button>
            <p id="sol4" class="solution">
                $S = 6a^2 \Rightarrow 24 = 6a^2 \Rightarrow a^2 = 4 \Rightarrow a = \mathbf{2 \text{ cm}}$.
            </p>
        </div>

        // Funkcia na zobrazenie/skrytie riešenia príkladu
        function showSolution(id) {
            const solution = document.getElementById(id);
            if (solution.style.display === "block") {
                solution.style.display = "none";
            } else {
                solution.style.display = "block";
            }
        }

        // Funkcia na vyhodnotenie kvízu so skórovaním podľa obtiažnosti
        function evaluateQuiz() {
            let totalScore = 0;
            const maxScore = 18; // 4x1 + 4x2 + 2x3 = 18 bodov
            
            // Definovanie správnych odpovedí a bodov (value je správna možnosť: a, b, c)
            const questions = {
                q1: { value: 'b', points: 1 }, // Prirodzené čísla
                q2: { value: 'c', points: 1 }, // Kvocient q
                q3: { value: 'b', points: 1 }, // Dĺžka jednej hrany
                q4: { value: 'b', points: 1 }, // S = 6a^2
                q5: { value: 'a', points: 2 }, // 5 + 3*2 = 11
                q6: { value: 'b', points: 2 }, // 4 * 2^2 = 16
                q7: { value: 'b', points: 2 }, // 4^3 = 64
                q8: { value: 'a', points: 2 }, // 2*5*1 = 10
                q9: { value: 'a', points: 3 }, // a2 = S3 / 3 = 15 / 3 = 5
                q10: { value: 'b', points: 3 } // V=8 -> a=2. S = 6*2^2 = 24
            };
            
            for (const qId in questions) {
                const checked = document.querySelector(`input[name="${qId}"]:checked`);
                if (checked && checked.value === questions[qId].value) {
                    totalScore += questions[qId].points;
                }
            }

            const successPercentage = Math.round((totalScore / maxScore) * 100);
            
            const output = document.getElementById("output");
            output.style.color = successPercentage >= 70 ? "green" : (successPercentage >= 50 ? "orange" : "red");

            output.innerHTML = `
                **Vyhodnotenie testu:**<br>
                Získané body: <span style="font-size: 1.2em;">${totalScore}</span> z ${maxScore} možných bodov.<br>
                Úspešnosť: <span style="font-size: 1.2em;">${successPercentage}%</span>.
            `;
        }
    </script>
